# ReadyGo Project Rules & Design System Guidelines

## Core Identity & Mission
ReadyGo is a pre-activity planning app for runners and cyclists that eliminates pre-session decision fatigue. It transforms 15 minutes of app-switching into a single "READY" tap.

## Tech Stack & Architecture
- Framework: React (Vite) + JavaScript/TypeScript
- Styling: Tailwind CSS (Mobile-first, high-contrast dark athletic theme)
- Motion & Micro-interactions: Framer Motion
- Icons: Lucide React (or SVG equivalents matching design)
- State Management: Zustand (Lightweight store for user profile, session loop, and app state)
- Layout Target: Mobile view (iPhone frame wrapper for desktop testing, responsive to native mobile viewports)

## Brand Design Tokens
- Background Base: Dark/Near-black (`#0D1317` / `#080C0E`)
- Sheet Overlay Background: Cool Light Grey (`#D1DCDA` / `#DCE4E2`)
- Surface Cards: Dark Slate (`#162026`)
- Accent Colors:
  - Brand Red / Active Primary: `#FF3B30` / `#FF453A`
  - Brand Lime Green / GO Action: `#00FF55` / `#70FF00`
  - Success / Active Green: `#30D158`
  - Warning / Danger Red: `#FF453A`
  - Warning / Soft Amber: `#FF9F0A`
- Typography: High-contrast athletic sans-serif, uppercase headings, compact track/leading.

## Tone of Voice & Copy Guardrails (STRICT)
- Language: British English ALWAYS (organised, colour, favour, recognise, session, route, kit, postcode).
- AI Engine Name: GOAI (Always uppercase). Uses first person ("I'll build your rides...").
- App Terminology:
  - Product Name: ReadyGo (One word, capital R, capital G)
  - Dashboard: Basecamp
  - Primary Action: READY
  - Action CTA: GO
  - Activity Types: Run / Cycle
- BANNED Words: powerful, seamless, unlock, journey, supercharge, smart (as adjective), leverage, cutting-edge, amazing, incredible, awesome, game-changer, next-level.
- Tone: Direct, human (always use contractions), dry wit ("OUCH!", "BLIP!"), earned encouragement. Say less.

## Interactive Micro-UX Standard
- Buttons: 
  - Primary CTAs must include active press-down feedback scale (`scale(0.97)` via Framer Motion).
  - "End Session" requires a long-press (hold) gesture.
- Input Fields: Focus rings, active white text, subtle placeholder contrast, shaking red error states.
- Modals & Sheets: Bottom-up slide transitions with drag-to-dismiss gesture handles.
- Navigation Modes: Tab bar switching between Basecamp, Saved, and Settings.
